# emviz 0.8.1

## Fixes

- Show counts for the stories, slices, and events allowed by the active timeline, actor, and review filters. Collapsed stories retain their counts.
- Remove gaps left by hidden stories and slices when actor filters narrow the canvas. Clearing the filter restores the original layout.

## Compatibility

Existing Event Model files need no migration. This patch changes only viewer presentation.

## Verification

The isolated real-server timeline journey passed with filtered count assertions. The navigation browser suite passed 20 cases, including actor filtering and the restored layout; the app browser suite passed 17 cases. The release candidate also passed `pnpm check`, `pnpm test`, `pnpm skills:validate`, and `pnpm --filter emviz pack --dry-run`. Skill eval cases are authored expectations, not agent evaluation results.

## Publication

This change prepares version 0.8.1. Publication requires the separate release workflow and its approvals.
