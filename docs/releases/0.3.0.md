# emviz 0.3.0

## Features

- Compact GWT scenario summaries keep diagrams readable even when a slice has many scenarios.
- Search and filter scenarios by name, then open full Given/When/Then details.
- Preserve scenario details in exported HTML and graph diffs, including removed scenarios and duplicate names.

## Fixes and UI improvements

- Keep the scenario list's scroll position when opening details and returning to the list.
- Use consistent button styles, focus indicators, and filter controls.

## Release process

- Publishing a stable GitHub Release now triggers npm publication. Pushing a tag alone does not publish.
- Release preparation creates a local commit and tag without pushing automatically.
- Maintainers must enable direct trusted publishing in npm before the first release using this process.
