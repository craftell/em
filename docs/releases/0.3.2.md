# emviz 0.3.2

## Fixes

- Keep same-named commands and queries in separate slices from sharing graph IDs and mixing their Incoming/Outgoing connections.
- Distinguish names and source paths that collapse to the same readable ID.
- Show each directed connection once, even when an event reference is repeated in YAML.
- Keep GWT nodes distinct and disconnected from behavior nodes.
- Resolve story membership by slice path rather than shared story names.
- Keep removed connections attached to their original nodes in diff views when slice titles and node names repeat.
- Use the same graph-building code for disk and browser imports.

## Compatibility

- Unambiguous node handles remain unchanged. Handles affected by a name collision can change when that collision appears or disappears.
- Existing exported HTML retains its embedded app and graph. Regenerate it from the original YAML with this version to apply these fixes.

## Verification

- Build and TypeScript checks passed.
- 45 unit tests and 10 browser tests passed, including real-YAML checks in live and exported views.
- The reported private model was not available for verification.
