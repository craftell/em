# emviz 0.7.0

## Features

- Choose how much of the graph the canvas draws with the toolbar's Edge visibility control. **Auto** (the default) shows intra-slice edges and, when a slice or node is selected, also its incoming and outgoing cross-slice edges. **Intra-slice only** keeps cross-slice edges hidden. **All** shows every domain edge allowed by the current timeline, actor, and review filters.
- Collapse and expand stories from their headers, or use Expand all stories and Collapse all stories. Each header shows a slice count, and the collapsed state persists. A collapsed story shows proxy connections that come from real domain edges, subject to the edge visibility mode. Legacy stories with the same name collapse independently.
- Navigate the canvas without moving the camera on selection. Hold Space and drag to pan. Two-axis wheel scrolling pans the canvas, and Shift-wheel pans horizontally. Modifier-wheel zoom and pinch zoom keep the point under the cursor fixed.
- Fix the wrapped toolbar and the open Actors panel covering sidebar actions. The workspace now follows their actual height, so the canvas is shorter while Actors is open.
- The `emviz` skill describes edge visibility, story collapse, and the navigation controls, and its timeline and feedback guidance is more complete. The `em-model`, `em-extract`, and `em-lint` skills have clearer feature-file and timeline references. The `emviz` skill pins `npx emviz@0.7.0`. These come from #13 and #14.

## Compatibility

- Canonical file formats and timeline ordering are unchanged. Edge visibility and story collapse are display choices and never edit the model.
- The sidebar Connections list still shows canonical incoming and outgoing connections, including edges hidden on the canvas. Focus selected node is still an explicit action.
- The CLI commands and flags are unchanged from 0.6.0.
- A browser import without an explicit model ID gets a new preference scope on each import. Exported HTML keeps that identity. A stable model ID in the sidecar file retains preferences across reimports.
