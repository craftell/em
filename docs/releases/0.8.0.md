# emviz 0.8.0

## Features

- Add optional `screen.url` to user screens. The top-right external-link icon and Details reference link open Figma or another HTTP(S) page in a separate tab.
- Link activation preserves selection and canvas position. Diff views retain the old reference URL when inspecting an old version.
- Reject unsafe or malformed URLs, credentials, relative paths, and URLs on system screens with L10 findings. The model remains inspectable without rejected links.
- Keep related modeling, lint, extraction, viewer skills, and verification instructions aligned with the URL field.

## Compatibility

Existing YAML requires no migration. This is a backward-compatible feature release.
Linked pages remain external and may require authentication. Standalone HTML preserves the URL without downloading the destination.
No image attachments or previews are included.
