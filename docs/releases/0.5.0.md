# emviz 0.5.0

## Features

- Queue selected nodes in the Agent sidebar, then send the whole queue as one batch. You can edit or remove unsent items. Selection changes, Refresh, and reload keep unsent drafts and queue items. An uncertain Send can be retried with the same batch ID and contents.
- Bind the viewer with `--host <IP>` to a concrete IPv4 or IPv6 address. Remote API access requires the session capability. The server accepts only the configured Host and Origin values. The default listener remains loopback.
- Add `POST /api/feedback/batch` for queued items. Existing `POST /api/feedback/request` clients remain supported.
- Add the `emviz` companion skill for opening the viewer and handling the feedback loop.

## Compatibility

- Existing Event Models remain supported. Actor registry support is unchanged from 0.4.0.
- The default listener is `127.0.0.1`. `--host` is explicit. Remote use requires an encrypted private network such as Tailscale. emviz uses HTTP.
- Legacy single-node feedback requests remain valid.
- The local server does not start an LLM or commit model edits.
- A turn comparison includes all file changes between claim and reply, including concurrent manual edits. It does not identify the author of each change.
- Feedback request history is kept in memory and is discarded when the server restarts.
- Browsers can block clipboard APIs on non-loopback HTTP origins. If a copy button does not work, select and copy the displayed text.
