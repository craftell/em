# emviz 0.6.0

## Features

- Bundle stories and timelines into one `*.feature.yaml` per feature. A feature file has `kind: feature`, `schema_version: 1`, and authored IDs for the feature, its stories, and its timelines. Slice files stay separate. See [the format, rationale, and migration notes](../feature-timelines.md) and the [example feature file](../examples/customer-onboarding.feature.yaml).
- Select a timeline in the viewer. Sibling steps stack vertically at the same horizontal stage, and a step with several predecessors starts to the right of all of them. The selected timeline is a projection of the canvas, so graph node IDs are not duplicated. All stories is the default.
- Validation reports finding F1 for invalid references, cycles, duplicate IDs, unsupported schema versions, and unsafe slice paths. The Node CLI and the browser app share one feature parser.
- Feedback snapshots, revision detection, Git sources, and exports include feature files. Diff views carry timeline metadata and show a notice when only the timeline layout changed.
- The `em-model`, `em-extract`, and `em-lint` skill references describe feature files and timelines. The `emviz` skill pins `npx emviz@0.6.0`.

## Compatibility

- Existing Event Models remain supported. Legacy `stories/*.yaml` files still load and appear under All stories.
- `after` only affects layout. Event and query edges stay canonical and are not changed by a timeline.
- Story and timeline identity comes from authored IDs, not file paths. Moving a feature file does not change identity.
- The same story can appear in several timelines. Within one timeline, each story and each slice can appear once, and a repeat is reported as a finding.
- Diff views show All stories and disable the timeline selector, so deleted elements stay visible.
- The CLI commands and flags are unchanged from 0.5.0. Feedback snapshots and `diff` Git sources now also read `*.feature.yaml` files.

## Known follow-ups

- A slice listed by two stories belongs to the last story in definition order. In the sample, `start-subscription` is also in the legacy "Subscription Checkout" story, so All stories draws it only under the new story and a diff marks its nodes changed. This predates timelines.
- The right sidebar floats over the canvas. The viewport fits only when a timeline is selected, so a story added by a refresh can sit under the sidebar.
- Timeline option labels include the feature file path and can truncate in the selector.
