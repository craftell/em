# emviz 0.4.0

## Features

- Send node feedback from the browser to an external agent that you start yourself. The agent receives the selected node's source and context, edits canonical YAML, and replies through the local CLI protocol.
- Review the current model, changes since the fixed session baseline, and changes from the most recent agent turn. Completed turn comparisons stay frozen after later file edits.
- Stop and resume feedback sessions from the browser, and stop or close the local server through the CLI.
- Define optional actor names and colors in `event-model/actors.yaml`, or configure a custom registry path with `paths.actors_file`.
- Show actor tags on user screens and filter by one or more actors or unassigned screens. Matching slices retain their scenarios, connected events, and one adjacent system slice without moving node positions.
- Preserve historical actor membership, names, and colors in diff views and standalone HTML exports.
- Add the `em-feedback` companion skill for the external-agent workflow.

## Fixes

- Read the fixed Git baseline correctly when the project is opened through a directory alias, including macOS `/var` and `/private/var` paths.
- Resolve Git baseline file lists from the repository root so projects in nested directories retain their historical model sources.

## Compatibility

- Existing models without an actor registry remain supported. Their `screen.actors` values supply the actor list.
- The local server does not start an LLM or commit model edits. Start your own agent and connect it with the `em-feedback` skill.
- A turn comparison includes all file changes between claim and reply, including concurrent manual edits. It does not identify the author of each change.
- Feedback request history is kept in memory and is discarded when the server restarts.
- Standalone HTML remains read-only and works without the project server. Regenerate existing exports to include the new actor controls.
