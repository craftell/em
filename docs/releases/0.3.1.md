# emviz 0.3.1

## Fixes

- Incoming and Outgoing now list only directly connected nodes, without repeating event names for each field.
- GWT nodes and missing endpoints are excluded from connection lists and copied connection context.
- Connection buttons still navigate to the neighboring node and preview the connection on hover or focus.

## Verification

- Build and TypeScript checks passed.
- All 25 unit tests passed.
- All 9 browser tests passed, including the new connection-list regression test.
